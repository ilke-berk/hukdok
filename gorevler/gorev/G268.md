## Hedef
Tarayıcının yükleyip zincirleyerek işleyebildiği, sahibine bağlı, süresi dolunca diskten de silinen çalışma dosyaları;
üç uç plan §3 sözleşmesiyle birebir.

## Kabul kriterleri
- [ ] `POST /api/pdf-araclari/yukle` (multipart `file`, tek dosya): uzantı `file_utils.ALLOWED_EXTENSIONS` (415), akışta
      `max_upload_mb` (413), `validate_file_type` magic-byte (415); `pdf_araclari.pdf_ye_cevir` → `PDF_ARACLARI_DIR`
      (`_cache_dir("PDF_ARACLARI_DIR", "pdf_araclari")`, volume) altında `<uuid>.pdf`; `DOWNLOAD_CACHE.set(id, {"path",
      "filename", "owner", "kaynak": "pdf_araclari", "sayfa", "sayfalar"})`; yanıt `Dosya` (§3). `ConversionBusyError` → 503,
      dönüşüm hatası → 422 (`error_kod: "donusum_basarisiz"`). Yüklenen ham dosya işlem sonrası silinir.
- [ ] `POST /api/pdf-araclari/islem` (JSON, Pydantic `IslemIstegi`: `islem` Literal, `girdiler` 1..`pdf_araclari_max_girdi`,
      `parametreler` dict, `cikti_adi?`): her girdi `DOWNLOAD_CACHE.get` + `owner == _owner_id(user)` + `kaynak ==
      "pdf_araclari"` değilse 404 (varlık maskelenir); `run_in_threadpool` içinde `_pdf_arac_semaphore` (2) —
      `acquire_conversion_slot` deseni, dolu → 503; `deadline = now + pdf_araclari_butce_saniye`; `ZamanAsimi` → 504;
      `ParametreHatasi` → 422; `SayfaSinirAsildi` → 413; `AracYok` → 503. Çıktılar yeni id'lerle cache'e; yanıt
      `{"ciktilar": [Dosya]}`. `@limiter.limit("30/minute")`, fonksiyon `request: Request` alır.
- [ ] Parametre doğrulaması Pydantic'te, işlem başına ayrı model (`BolParametreleri` vb., `extra="forbid"`); çekirdek
      ikinci kez doğrular (savunma derinliği), route 422'ye çevirir.
- [ ] `GET /api/pdf-araclari/onizleme/{id}/{sayfa}?genislik=240`: sahiplik 404; `image/png`, `Cache-Control: private,
      max-age=3600`; sayfa aşımı 404; genişlik sınırı 422.
- [ ] `GET /api/download/{id}` mevcut uçtan DEĞİŞMEDEN iner (test: `filename` cache'teki ad, `Content-Disposition`).
- [ ] Payload temizliği: `_cleanup_process_cache`'in `on_evict`'i `entry.get("kaynak") == "pdf_araclari"` ise
      `file_utils.safe_remove(entry["path"])`; başka kayıtlara dokunmaz (test: `/process` kaydı evict'te dosyası kalır,
      pdf_araclari kaydı silinir). PDF aracı uçları da isteğin başında `_cleanup_process_cache()` çağırır.
- [ ] `api.py`: `app.include_router(pdf_araclari.router)` (`documents.router` satırının yanına, yorumla).
- [ ] Bekçi testi: tüm uç yolları `/api/` ile başlar (nginx `location /api` yeter; `nginx.conf`'a dokunulmadı — test,
      `nginx.conf`'ta `pdf-araclari` geçmediğini ve route prefix'ini doğrular).
- [ ] Route testleri `test_g078_son_belgeler_ucu.py:38-63` kalıbıyla (`dependency_overrides`, `TestClient(app,
      raise_server_exceptions=False)`): yükle→işlem→önizleme→indir zinciri; başka kullanıcının id'si 404; 21 girdi 422;
      yanlış `islem` 422; semafor dolu 503 (monkeypatch); `ZamanAsimi` 504; magic-byte sahte `.pdf` 415; rate limit
      sabitinin varlığı.
- [ ] Log: nihai hata TEK ERROR (route'ta, `error_kod` ile), 4xx'ler WARNING.
