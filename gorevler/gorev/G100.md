## Hedef

2026-08-22 CSP ihlal turu (lokal 8080, Report-Only): uygulamanın kendisi
politikayla uyumlu — `script-src`/`style-src`/`font-src`/`frame-src` ihlali
sıfır (tek ihlal sınıfı lokal `VITE_API_URL` artefaktıydı, prod'da yok). Kod
okumasında turun tetiklemediği **iki enforce kırıcı** bulundu; ikisi de
`window.open("", "_blank")` + `document.write` ile açılan yazdırma popup'ı:

1. `DashboardCalendar.tsx` `printReport`: yazılan HTML'de
   `<body onload="window.print()">` — inline event handler (`script-src-attr`).
2. `YetkiBelgesiModal.tsx` `handlePrint`: yazılan HTML'de
   `<script>window.onload=function(){window.print()}</script>` — inline script
   (`script-src-elem`).

Kontrol deneyi ana dokümanda aynı iki deseni `script-src-attr|report` ve
`script-src-elem|report` olarak yakaladı — zorlayıcı politika altında kesin
engellenir. `about:blank` popup'ın bu politikayı miras alıp almadığı lokal
panelde doğrulanamadı (popup engelleyici); spec mirası öngörür. Belirsizliği
taşımaya gerek yok: düzeltme ucuz ve her CSP altında çalışır.

## Yapılacak

İki yerde de yazdırma tetiği popup'ın İÇİNDEN değil **açandan** verilir:

```ts
w.document.open(); w.document.write(html); w.document.close();
w.addEventListener("load", () => w.print(), { once: true });
// document.close() senkron yükleme bitirmiş olabilir: readyState zaten
// "complete" ise load hiç gelmez → o durumda doğrudan w.print().
```

Yazılan HTML'den `onload=` ve `<script>` tamamen çıkar. `<style>` bloğu kalır
(`style-src 'unsafe-inline'` bilinçli açık, G091). `window.print` çağrısının
popup kapanmadan önce koşması kritik — `readyState` kontrolü bu yüzden.
