# G194 — Teslim cevap yüklemesi: SharePoint yüklemesinden önce transaction'ı kapat

- **Bant:** backend
- **Bağımlı:** -
- **Dosya kapsamı:** `backend/services/teslim_cevap.py` (yalnız `cevap_yukle`), `backend/tests/test_g110_teslim_cevap.py` (yalnız YENİ test eklenir)
- **Dokunma:** `backend/database.py`, `backend/services/teslim_kutusu.py`, `backend/sharepoint/**`, `docker-compose.yml`, mevcut test gövdeleri (değişmesi gerekirse BLOKE bırak — test değiştirme izni YOK)

## Hedef
`cevap_yukle` (`services/teslim_cevap.py:477-553`) oturumu açar, teslimi okur, `eslesme_csv_uret(db=session)`
ile sorgu koşar ve ardından SharePoint yükleme döngüsünü (`_spu.upload_file_to_sharepoint`, uploader iç
retry'ı dahil) AYNI açık transaction içinde çalıştırır; `session.commit()` en sondadır. G191
`idle_in_transaction_session_timeout=60 s` açınca yüklemeler 60 sn'yi aşarsa sunucu oturumu keser, son commit
`OperationalError` verir, `cevap_yuklendi` yazılmaz ve `bekleyen_cevaplari_yukle` (`:567-577`) rollback +
WARNING ile turu geçer. Düzeltme: yükleme döngüsü başlamadan önce transaction kapatılır (döngünün ihtiyaç
duyduğu değerler yerel değişkenlere alınır, döngü içinde ORM nesnesine dokunulmaz — `expire_on_commit`
yeni SELECT açıp transaction'ı yeniden başlatır); döngüden sonra teslim `tk._teslim_getir` ile YENİDEN
okunur, not + `cevap_yuklendi` yazılır, commit.
