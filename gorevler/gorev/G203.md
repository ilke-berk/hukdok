- **Dokunma:** `infra/**` (host nginx — G207), `frontend/src/**` (G204-G206), backend Python kodu, `backend/tests/test_port_baglama.py` (değişmeden yeşil kalmalı)

Kaynak: `gorevler/KUYRUK.md` ÖNCELİK 2 yorumu (karar: Hukukbot'a yalnız HukuDok üzerinden erişilir).

## Hedef
HukuDok'un konteyner nginx'i Hukukbot API'sinin YALNIZ kullanıcı uçlarını `/hukukbot-api/` öneki altında
`hukukbot_api:8010`'a proxy'ler; hukbot'un `/ingest/*` ve diğer iç uçları dışarıdan erişilemez kalır.
Frontend konteyneri `hukuk_shared` ağına katılır. Sayfanın markdown render'ı için iki npm paketi eklenir.

## Kabul kriterleri
- [ ] `nginx.conf`'ta regex location: `^/hukukbot-api/(ask|sessions|download)(/|$)` → önek atılarak
      `hukukbot_api:8010`'a gider (ör. `/hukukbot-api/sessions/abc` → `/sessions/abc`). `health` dahil başka
      hiçbir yol proxy'lenmez; `/hukukbot-api/ingest/...` SPA'ya/404'e düşer, hukbot'a GİTMEZ.
- [ ] **Gecikmeli DNS şart:** `resolver 127.0.0.11 valid=30s ipv6=off;` + `set $hukukbot_upstream ...` değişkeniyle
      `proxy_pass`. Gerekçe yorumda: düz `proxy_pass http://hukukbot_api:8010` hukbot stack'i kapalıyken HukuDok
      nginx'inin AÇILMASINI engeller (upstream çözülemez → konteyner kalkmaz); değişkenle yalnız o istek 502 olur.
      Lokal kanıt: hukbot kapalıyken `docker compose up -d frontend` + `curl -sI localhost:8080/` 200; `/hukukbot-api/sessions` 502.
- [ ] `/ask` NDJSON akışı için `proxy_buffering off`, `proxy_read_timeout 300s` (mevcut 300s çizgisi), `client_max_body_size` makul.
      `Authorization` başlığı olduğu gibi geçer; `X-User-OID` başlığı proxy'de SİLİNİR (`proxy_set_header X-User-OID "";` —
      hukbot'un dev bypass yoluna dışarıdan başlık sızmasın).
- [ ] Location'da `add_header` KULLANILMAZ (kullanılırsa beş güvenlik başlığı AYNEN tekrar — `nginx.conf:48-51` tuzağı);
      tercih: hiç `add_header` yok → server düzeyi başlıklar kalıtılır.
- [ ] `docker-compose.yml` `frontend.networks`: `hukudok-network` + `hukuk_shared`. Port girdisi değişmez;
      `test_port_baglama.py` yeşil.
- [ ] `frontend/package.json`: `react-markdown` + `remark-gfm` (React 18 uyumlu en güncel sürümler; hukbot'taki
      `react-markdown` 9 / `remark-gfm` 4 çizgisi referans), lock güncel; `npm --prefix frontend ci` temiz, `npm audit` yeni yüksek bulgu yok.
- [ ] Yeni bekçi `backend/tests/test_nginx_hukukbot.py` (repo kökü görünmezse `test_port_baglama.py` gibi skip):
      (a) `/hukukbot-api` location'ı allowlist regex'i taşır ve `ingest`/`health` içermez,
      (b) proxy_pass değişkenlidir ve aynı blokta `resolver` vardır,
      (c) `/export` konteyner nginx'inde hâlâ YOK (`nginx.conf:114` kuralı),
      (d) compose'da frontend `hukuk_shared`'dadır.
- [ ] `docker compose exec frontend nginx -t` başarılı (rebuild sonrası).

## Doğrulama
- `docker compose build frontend && docker compose up -d frontend` → `docker compose exec -T frontend nginx -t`
- `curl -sI http://localhost:8080/` (200) · `curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/hukukbot-api/ingest/hukdok` (hukbot'a gitmediği görülür)
- `docker compose exec -T backend python -m pytest` (yeni bekçi konteynerde skip; CI eşdeğeri için `/ci-kontrol` §1)
- `npm --prefix frontend ci && npm --prefix frontend test && npm --prefix frontend run build`
