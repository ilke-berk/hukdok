## Hedef
Avukat ajan sonucunu masasında inceler: işaret sütunlu DOCX liste + adayların birebir metni + ölçüm aracının okuduğu
JSON tek zip'te iner ve belgenin yanına arşive yazılır. Taslağa alınan emsal kararlar Word'de künyesiyle görünür.

## Kabul kriterleri
- [ ] `inceleme_paketi.olustur(sonuc, kararlar) -> bytes` (zip): `inceleme.docx` (python-docx; başlık = belge sha ilk 12 +
      tarih; tablo: sıra, künye (mahkeme · E/K · tarih), puan, gerekçe, doğrulanmış alıntı, fark, kart no, "uygun /
      kısmen / değil" işaret sütunu boş kutularla), `kararlar/<sıra>_<esas>_<karar>.txt` (birebir metin, `karar_depo`'dan;
      dosya adında yalnız numara — ad yok), varsa `kararlar/<…>.pdf` (`LEXIS_KARAR_PDF_DIZINI` tanımlı ve
      `karar_dosyalari.ad` dosyası oradaysa; yoksa atlanır, README "insan kararı: host dizini salt okunur bağlanır"),
      `sonuc.json` (öneri listesi + sayılar + model + istem sürümü; `araclar/emsal_ajan_olcum.py` G265'te bunu okur —
      şemayı README'ye yaz).
- [ ] `GET /emsal-sonuc/{sha256}/indir`: yalnız yönetici; sonuç yoksa 404; `Content-Disposition: inceleme_<sha12>.zip`,
      `Cache-Control: no-store`; log yalnız sha12 + boyut.
- [ ] Paket arşive de yazılır (G260 istemcisi, `<klasör>/<yıl>/<sha256>/inceleme.docx` + `sonuc.json`; her yeni koşu
      üzerine yazar); env kapalıysa atlanır (`arsiv: "kapali"`). Arşiv hatası indirmeyi engellemez.
- [ ] Word künye satırı: `EkranTaslagi.emsal_kararlar: list[int]` (yeni, isteğe bağlı; eski taslak çalışır) → Word'de
      "Emsal kararlar" etiketli satır(lar) `bicim.etiket_satiri_yaz` ile (künye: mahkeme · E/K · tarih; metin DEĞİL);
      dört iskelette de (`ANADOLU` yerinde doldurma yolu dahil) yazılır; `bicim_denetle` uyarısız. Boş listede satır yazılmaz.
- [ ] Paketteki hiçbir dosya adı ve DOCX içeriği belgenin orijinal adını taşımaz; test, sentetik sonuçla zip içeriğini
      (dosya listesi, DOCX tablo başlıkları, JSON şeması) kilitler.
- [ ] README "İnceleme paketi" + PLAN.md.
