# G030 — B.1: pytest-cov + CI kapsam kapısı

- **Bant:** backend
- **Bağımlı:** -
- **Dosya kapsamı:** backend/requirements-dev.txt, backend/pyproject.toml, .github/workflows/ci.yml
- **Dokunma:** backend/tests/conftest.py (DOKUNMA — G031/G033 orada çalışacak), backend/requirements.txt (prod imajı; dev aracı BURAYA GİRMEZ)

## Hedef

Kapsam ölçümü bugün klondan tekrar üretilemiyor: `requirements-dev.txt` içinde
`pytest-cov` YOK (doğrulandı — dosyada yalnız pytest/httpx/ruff/mypy var). Plan §4'ün
"%58,5 uygulama kapsamı" rakamı bu yüzden doğrulanamaz bir iddia.

`pytest-cov`'u dev bağımlılıklarına ekle, CI'da `--cov` koştur ve **mütevazı** bir
`--cov-fail-under` eşiği kur. Eşik bir hedef değil, **gerilemeyi yakalayan taban**dır.

## Kabul kriterleri

- [ ] `backend/requirements-dev.txt`'e `pytest-cov` sabit sürümle eklendi (`==`), prod
      `requirements.txt`'e DOKUNULMADI
- [ ] Kapsam **önce ölçüldü**, gerçek rakam görev raporuna yazıldı; `--cov-fail-under`
      ölçülen değerin **2 puan altına** kuruldu (tahmin YASAK — ölçülen sayı rapora girer)
- [ ] Kapsam yalnız uygulama kodunu sayar: `--cov=.` ile birlikte `tests/` ve `scripts/`
      dışlandı (`.coveragerc` ya da `pyproject.toml` `[tool.coverage.run] omit`)
- [ ] `pyproject.toml`'daki `addopts = "-q"` **bozulmadı** — `--cov` bayrakları addopts'a
      GİRMEZ (lokal koşuyu yavaşlatır); yalnız CI adımına eklenir
- [ ] `.github/workflows/ci.yml` backend job'unda pytest adımı `--cov --cov-fail-under=N`
      ile koşuyor; N görev dosyasında gerekçeli yazılı
- [ ] Dev araçları kurulu olmayan bir konteynerde `python -m pytest` hâlâ çalışıyor
      (cov bayrakları addopts'ta olmadığı için) — bu elle doğrulanıp rapora yazıldı

## Doğrulama

- `docker compose exec -T backend pip install -r requirements-dev.txt`
- `docker compose exec -T backend python -m pytest`
- `docker compose exec -T backend python -m pytest --cov=. --cov-report=term-missing`
- `docker compose exec -T backend python -m ruff check .`
- `docker compose exec -T backend python -m mypy`
