# G101 — CSP zorlayıcıya geçer: `-Report-Only` eki düşer

- **Bant:** docs
- **Bağımlı:** G100
- **Dosya kapsamı:** nginx.conf (yalnız satır 54 civarı CSP başlığı),
  docs/mimari/deploy-ve-altyapi.md (§11), docs/mimari/kimlik-ve-token.md (§6
  açık kalemler satırı)
- **Dokunma:** frontend/** (DOKUNMA), backend/** (DOKUNMA), nginx.conf'un
  diğer blokları (DOKUNMA — özellikle `/export` kuralı ve proxy timeout'ları)

## Hedef

G091 başlığı Report-Only olarak koymuş ve zorlayıcıya geçişi "ihlal listesine
bakan ayrı görev"e bırakmıştı. O liste 2026-08-22'de lokal 8080'de toplandı:

- Gezilen: login (SSO), pano, `/upload`, `/cases`, `/clients`,
  `/activity-history`, `/admin`, tema geçişi, zil paneli.
- `script-src`, `style-src`, `font-src`, `img-src`, `frame-src`: **0 ihlal**.
  Google Fonts yüklendi, `index.html`'deki inline `ld+json` bloğu raporlanmadı,
  MSAL yönlendirmesi sorunsuz.
- `connect-src`: 32 ihlal, hepsi `http://localhost:8001` — yalnız lokal
  `.env`'deki `VITE_API_URL` artefaktı; `.env.example`/compose/`deploy.sh`'de
  yok, prod API'yi aynı origin'den nginx proxy'siyle çağırır → prod'da oluşmaz.
- Kod okumasıyla bulunan iki inline-script popup'ı G100'de kapatıldı.

Politika METNİ değişmez; yalnız başlık adı `Content-Security-Policy` olur.
`connect-src 'self' https://login.microsoftonline.com` aynen kalır.

## Kabul kriterleri

- [ ] `nginx.conf`te `Content-Security-Policy` (Report-Only DEĞİL) başlığı var,
      `always` ile; politika dizesi G091'dekiyle **birebir aynı**
      (`git diff` yalnız başlık adını değiştiriyor)
- [ ] `Content-Security-Policy-Report-Only` başlığı kalmadı
- [ ] `/export` konteyner nginx'ine EKLENMEDİ; proxy blokları ve timeout'lar
      değişmedi (`git diff nginx.conf` tek satır)
- [ ] nginx sözdizimi denetimi geçiyor (G091'deki tek seferlik konteyner
      komutu; çalışan stack'e DOKUNMAZ, `docker compose build/up` ÇAĞRILMAZ)
- [ ] `deploy-ve-altyapi.md` §11: Report-Only gerekçesi "tarihçe"ye döner,
      2026-08-22 ihlal turu özeti (gezilen sayfalar, 0 ihlal, lokal connect-src
      artefaktı) ve G100 ön koşulu yazılır; "enforce'a geçiş ön koşulu" cümlesi
      "geçildi (G101)" olur
- [ ] `kimlik-ve-token.md` §6 açık kalemlerden "CSP hâlâ Report-Only" satırı düşer
- [ ] Dokümanda **deploy sonrası insan turu** maddesi var: yazdırma popup'ları
      (G100), dava kartından PDF açma, belge yükleme; ve ihlal görülürse geri
      dönüş = başlık adına `-Report-Only` ekini geri koymak (tek satır, imaj
      rebuild gerekir)

## Bu görevin KAPSAMADIĞI doğrulama (kullanıcıya kalır)

Başlığın canlı görünmesi frontend imajının yeniden kurulmasını gerektirir
(docs bandı worktree'de koşar, stack'e dokunmaz):

```
docker compose build frontend && docker compose up -d frontend
curl -sI http://localhost:8080/ | grep -i content-security-policy
```

Ardından tarayıcı turu: login → pano → Takvim "Yazdır" → Yetki Belgesi "Yazdır"
→ dava kartından PDF aç → belge yükle. Konsolda "Refused to" satırı **olmamalı**.
Lokal `.env`'de `VITE_API_URL` doluysa `connect-src` ihlali görülür — bu lokal
artefakttır, prod'u temsil etmez (boşaltıp rebuild ile doğrulanabilir).
