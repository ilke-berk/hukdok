# G099 — cache_manager: iki worker'ın makedirs yarışı sahte ERROR basıyor

- **Bant:** backend
- **Bağımlı:** -
- **Dosya kapsamı:** backend/managers/cache_manager.py,
  backend/tests/test_g099_cache_dir.py (YENİ)
- **Dokunma:** backend/api.py (DOKUNMA — çağıran aynı kalır),
  backend/routes/processing.py (DOKUNMA)

## Hedef

Her konteyner açılışında (2026-08-22'de iki kez gözlendi) şu satır geliyor:

```
ERROR CacheManager: Failed to create cache directory: [Errno 17] File exists:
'/home/appuser/AppData/Local/HukuDok/cache'
```

Sebep `cache_manager.py:25-31`: `ensure_cache_dir` önce `exists` bakıyor, sonra
`os.makedirs` çağırıyor. Backend **2 uvicorn worker** ile kalkıyor
(`docker-entrypoint.sh`), ikisi de lifespan'de aynı anda bu fonksiyona giriyor:
ikisi de "yok" görüyor, biri yaratıyor, diğeri `EEXIST` ile düşüyor. Klasik
TOCTOU; zararsız (dizin var, cache çalışıyor) ama:

- Log sözleşmesine aykırı: ERROR yalnız nihai başarısızlık için (CLAUDE.md
  "Log sözleşmesi"). Bu bir başarısızlık değil.
- GCP log-tabanlı ERROR-oranı alarmı (`docs/mimari/deploy-ve-altyapi.md` §8)
  bunu sayıyor — her deploy'da sahte bir ERROR tıkı. Açılışta "0 ERROR"
  deploy kapısını (deploy_13/14 notları) kirleten tek satır bu.

## Yapılacak

`os.makedirs(CACHE_DIR, exist_ok=True)` — `exists` ön kontrolü kalkar (yarışın
kendisi o). Geriye kalan gerçek hata (izin yok, salt-okunur FS) **hâlâ** ERROR:
o durumda cache gerçekten yazılamaz, sözleşme ona uyuyor.

Bu kadar. Dosyanın geri kalanına (atomik yazma, load/save) dokunulmaz.

## Kabul kriterleri

- [ ] `ensure_cache_dir` `exist_ok=True` kullanıyor; `os.path.exists` ön
      kontrolü yok
- [ ] Dizin zaten varken çağrı **hiçbir log basmıyor** (test: `caplog` boş)
- [ ] Dizin yokken çağrı dizini yaratıyor, log basmıyor (test, `tmp_path` +
      `monkeypatch.setattr(cache_manager, "CACHE_DIR", ...)`)
- [ ] Gerçek hata (örn. `makedirs` monkeypatch ile `PermissionError` fırlatır)
      → tek ERROR, istisna çağırana yükselmiyor (mevcut sözleşme: açılış
      cache yüzünden durmaz) (test)
- [ ] İki eşzamanlı çağrı (thread) → dizin var, ERROR yok (test; yarışı kesin
      üretmek şart değil — `exist_ok` ile sonuç deterministik, test bunu kilitler)
- [ ] `load_cache`/`save_cache` diff'siz
