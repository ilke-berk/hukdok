## Hedef

Plan §5 (kullanıcı kararı 07.09): "birden fazla şehir seçilemiyor" sınıfı sorunun kökü, kontrol türünün
kolon TİPİNDEN türetilmesi. Yeni kural: işaretli metin kolonlarda DISTINCT değer sayısı eşiğin altındaysa

## Yapılacaklar

1. **Veriden liste:** `Kolon.veriden_liste: bool = False`; `secenekleri_getir` genişler: veriden liste kolonda
   `SELECT deger, COUNT(*) … GROUP BY … ORDER BY COUNT DESC, deger` (kaynağın `kisitlar(tenant_id)` + boş hariç),
   eşik `settings.rapor_secenek_esigi` (env `RAPOR_SECENEK_ESIGI`, varsayılan 100): sayı ≤ eşik → `kontrol=
   "coklu_secim"`, `secenekler` dolu, `secenek_kaynagi="veri"`; aşarsa `kontrol="metin_icerir"`, `oneriler`
   (G137). Katalog kolonuna `secenek_kaynagi: "sabit"|"veri"|null`. İşaretler plan §5.2 listesi. Kolon `tip`
   "metin" kalır. Katalog önbelleği (60 sn, tenant anahtarlı) bu sorguları da kapsar — ek DISTINCT maliyeti raporda
   ölçülür (lokal 14.5k dava / 2k müvekkil, ms).
2. **Seçenek etiketleri:** `Kolon.secenek_etiketleri: Mapping[str,str]|None`; katalogda `secenek_etiketleri`;
   `client_type` için plan §5.2 haritası. Filtre değeri ham kalır (motor değişmez).
3. **`in` içinde boş:** `Filtre` doğrulaması `in` listesinde `None` öğesine izin verir (diğer op'larda 422
   `{"alan","sebep":"null yalnız 'in' listesinde"}`); tipli değer denetimi `None`'ı atlar; motor `_ifade_kosulu`:
   `in` → `or_(ifade.in_(dolu), ifade.is_(None))` (dolu boşsa yalnız `is_(None)`); türetilmiş EXISTS filtrelerinde
   `in` + `null` → "koşula uyan taraf yok" OR EXISTS(in) (muvekkil_kategorisi için). `AsistanFiltre.degerler`'de
   `"(boş)"` (ve "(bos)") sabiti `None`'a çevrilir; prompt'a tek cümle: "boş değeri de dahil etmek için `(boş)`".
4. **Sanal arama kolonu:** `Kolon.secilebilir: bool = True`; her kaynağa `arama` (plan §5.2 kolon listeleri;
   `_turetilmis(..., filtrelenebilir=True, secilebilir=False, izinli_oplar=("contains",))`, `filtre_ifadesi`
   = OR'lu ILIKE'lar; taraf adları EXISTS). `tanimi_dogrula`: `kolonlar`/`siralama` içinde `secilebilir=False`
   → 422 ("yalnız filtre alanı"); `_kendini_denetle`: varsayılan kolonlar ve kolon setleri `secilebilir` olmalı.
   Katalog kolonuna `secilebilir`. `katalog_metni`: "yalnız filtre" şerhi; `grup` "Arama".
5. **Hızlı filtre sunumu:** `HizliFiltre.sunum` (Literal plan §5.2) + `etiket`; denetim: `arama` yalnız `arama`
   kolonunda, `cipler` yalnız `secenekler`i olan kolonda, `var_yok` yalnız sayı/para, `bos_anahtari` her tipte.
   Müvekkiller listesi plan §5.2 sırası; Davalar/Belgeler/Föyler başına `arama(arama)`. Katalog `hizli_filtreler`
   öğesine `sunum` + `etiket`.
6. **Testler** (`test_g137` `env` deseni): veriden liste — eşik altı `coklu_secim` + sıklık sırası + tenant/
   silinmiş hariç; eşik üstü `metin_icerir` + öneriler; `RAPOR_SECENEK_ESIGI` env (monkeypatch settings);
   `secenek_etiketleri` client_type; `in` içinde `null` → IN OR IS NULL (davalar `court`, müvekkiller `il`,
   türetilmiş `muvekkil_kategorisi`); `null` başka op'ta 422; `arama` contains beş kolonda bulur, `kolonlar`da 422,
   kolon setlerinde yok, katalogda `secilebilir=false`; hızlı filtre `sunum` şekli + denetim hataları (`ValueError`
   import anında); asistan "(boş)" çevirisi; katalog şekli (anahtar kümesi güncel).
