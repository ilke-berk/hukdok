## Hedef

`docs/mimari/` altında **kimlik doğrulamanın kendi dokümanı yok**: token akışı
`genel-bakis.md:136-190` arasına dağılmış birkaç cümle. 2026-08-22 token
analizinde ortaya çıkan bilgi (akış, süreler, doğrulama zinciri, açık kalemler)
sohbette kaldı — kalıcı yere yazılmazsa bir sonraki sıfır-context oturum aynı
keşfi baştan yapar.

değiştiriyor (`auth_verifier.py`, açılış guard'ları, oturum kapanış yolu);
doküman **son hale** karşı yazılmalı, yoksa yazıldığı gece bayatlar. G095 ayrıca
`postLogoutRedirectUri`'yi düzeltiyor — çıkış akışı anlatılırken güncel hedef
yazılmalı.

## Yazılacak: `docs/mimari/kimlik-ve-token.md`

ALTIN KURAL geçerli — her iddia koddan okunarak doğrulanır, bu görev dosyasından
ya da sohbetten KOPYALANMAZ. Aşağıdakiler içerik iskeletidir, alıntı değil:

1. **Kullanıcı akışı:** `loginRedirect` (`pages/Login.tsx`) → Authorization Code
   + PKCE (MSAL Browser v5, implicit yok) → istenen scope
   `api://<client_id>/access_as_user` (`config/msalConfig.ts`) →
   `cacheLocation: "sessionStorage"` (sekme kapanınca token uçar) →
   her istekte `acquireTokenSilent` + `Bearer` (`lib/api.ts`) → 401'de
   `forceRefresh` ile TEK tekrar, yine 401 ise `SESSION_EXPIRED_EVENT` +
   `logoutRedirect`.
2. **Backend doğrulama zinciri:** imzasız decode → `tid` → `ALLOWED_TENANTS`
   allowlist → tid'in JWKS'i → RS256 imza + `aud` + `exp` (+ G092'den sonra
   `iss`) → `dependencies.get_current_user`/`get_current_tenant`. Durum tutulmaz,
   session yoktur. Admin kapısı `ADMIN_EMAILS` (`routes/config.py`).
3. **Süre tablosu.** Koddan doğrulanabilenler (idle timeout ve uyarı süresi
   `App.tsx` + `hooks/useIdleTimeout.ts`; sessionStorage'ın sekme ömrü) ile
   **Entra tarafında belirlenenler AYRI işaretlenir**. Access token ~60-90 dk ve
   SPA refresh token 24 saat değerleri **Entra varsayılanıdır, tenant'ta teyit
   EDİLMEMİŞTİR** — doküman bunu böyle yazar, kesinmiş gibi değil. Teyit
   kullanıcıya ait bir adımdır (Entra admin center → token lifetime /
   Conditional Access sign-in frequency).
4. **Backend→Graph ayrı akış:** client-credentials (app-only), MSAL
   `ConfidentialClientApplication` + süreç-içi cache, Graph 401'de `force_refresh`
   (`sharepoint/auth_graph.py`). Kullanıcı oturumundan bağımsızdır. G093'ün
   secret expiry uyarısı burada anılır.
5. **Yanıltıcı görünen ama kapı OLMAYAN şey:** `pages/Login.tsx`'teki
   `ALLOWED_DOMAINS` sabiti **yalnız giriş ekranında metin olarak gösteriliyor**,
   hiçbir yerde zorlanmıyor (kod okunarak doğrulanacak). Gerçek kapılar: Azure AD
   app registration + `ALLOWED_TENANTS`. Bu netleştirme dokümanın en değerli
   satırlarından biri — birinin "domain kısıtımız var" sanmasını önler.
6. **Bilinen açık kalemler** (çözüm iddiası değil, envanter):
   - CSP hâlâ Report-Only (`nginx.conf`, G091) — zorlayıcıya geçişin ön koşulu
     insan turuyla toplanan ihlal listesi
   - `scp` zorunluluğu + audience daraltma: G092 gözlem modunda bıraktı, faz 2 açık
   - Token iptali gecikmesi: CAE yok, access token `exp`'e kadar geçerli;
     azaltıcılar idle timeout ve refresh token'ın 24 saatlik tavanı
   - Yetkilendirme granülaritesi: tenant üyeliği = tam erişim; rol/grup yok
