# G184 — useConfig: liste başına hook (`useConfigList`) + QueryClient odak yenilemesi kapalı

- **Bant:** frontend
- **Bağımlı:** G182
- **Dosya kapsamı:** `frontend/src/hooks/useConfig.ts`, `frontend/src/hooks/useConfig*.test.tsx`, `frontend/src/App.tsx` (yalnız `new QueryClient(...)` satırı)
- **Dokunma:** `useConfig` tüketicileri (16 dosya — bu görevde DEĞİŞMEZ, G185'te taşınır), `frontend/src/lib/api.ts`

Kaynak: `docs/arsiv/performans-denetimi-2026-09-14.md` F3.

## Hedef
`useConfig()` tek hook'ta 32 ayrı `useQuery` kuruyor (`useConfig.ts:147-188`); 1-2 liste
kullanan 14+ tüketici 32 observer'a abone oluyor. `App.tsx:34` `new QueryClient()` varsayılan
`refetchOnWindowFocus: true` → 5 dk staleTime dolunca her pencere odağında 32 istek. Bu görev
hook katmanını hazırlar: mevcut `useConfig()` sözleşmesi (dönüş şekli, `requiredFieldsError`
vb.) birebir korunur, yanına liste başına abone olan `useConfigList(key)` gelir; tüketici
taşıma G185'te.

## Kabul kriterleri
- [ ] `useConfigList(key: ConfigListKey)` dışa verilir: tek `useQuery`, `CONFIG_KEYS[key]` ile aynı queryKey ve aynı `queryOpts` (staleTime, retry:false, enabled) → `useConfig()` ile önbelleği PAYLAŞIR (aynı anahtar, çift istek yok). Dönüş: `{ data, isLoading, isError, error }` + listeye özgü türetilmiş yardımcılar gerekiyorsa (örn. `lawyers` için mevcut sıralama/filtreleme aynı fonksiyonla).
- [ ] `useConfig()` dönüş tipi ve alan adları DEĞİŞMEZ (16 tüketici derlenmeye devam eder); içeride ister eski 32 `useQuery` kalsın ister `useQueries` — davranış aynı.
- [ ] `App.tsx`'te `new QueryClient({ defaultOptions: { queries: { refetchOnWindowFocus: false } } })`; gerekçe yorumu (32 liste × odak). `useNotifications` 60 sn poll'u ve diğer `refetchInterval` kullanımları etkilenmez (doğrula, rapora yaz).
- [ ] Test: `useConfigList("lawyers")` monte edilince yalnız `/api/config/lawyers` çağrılır (fetch mock sayacı = 1); aynı bileşende `useConfig()` + `useConfigList("lawyers")` birlikte → `/api/config/lawyers` yine 1 kez.
- [ ] Test: pencere odağı olayında (`window.dispatchEvent(new Event("focus"))` + `visibilitychange`) bayat sorgu YENİDEN çekilmez.
- [ ] Mevcut `useConfig*.test.tsx` testleri değişmeden yeşil.
