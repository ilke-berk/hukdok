- **Bant:** backend
- **Bağımlı:** G183
- **Dosya kapsamı:** `backend/database.py` (`_TRGM_INDEXES` sözlüğü + `_DUSURULECEK_INDEXLER`), `backend/tests/test_index_envanteri.py`, `backend/tests/test_g043_index_ve_avukat_filtresi.py`, `backend/tests/test_migrations_drop.py`, `docs/kararlar/018-index-temizligi-37-kalem.md` (ek not)
- **Dokunma:** `backend/managers/case_manager.py` (G190 alanı — DEĞİŞMEZ), `backend/models.py` (`uq_cases_sistem_no` UNIQUE kısıtı DOKUNULMAZ — kullanıcı kararı)

Kaynak: `docs/arsiv/performans-denetimi-2026-09-14.md` D2 (kanıt: `cases.tku_no`/`sistem_no`
14.578 satırda 0 dolu; `case_foys.tku_no` 8.140 / `sistem_no` 8.395 / `onceki_tracking_no` 223

## Hedef
Arama (`_term_case_id_selects`) TKU/sistem no'yu `case_foys` üzerinden buluyor (G123) ama
trigram index'ler hâlâ boş legacy `cases.tku_no`/`sistem_no` kolonlarında. Index'i doğru yere taşı.
Trigram index'ler BİLİNÇLİ olarak `_TRGM_INDEXES` sözlüğüyle (hata-toleranslı blok, `pg_trgm`
extension'ından sonra) yaratılır — `("index", ...)` op'una YAZILMAZ (G043 notu, `database.py`
"NOT (G043)"). Düşürme ise G042 deseniyle `_DUSURULECEK_INDEXLER` → `("index", ...)` op'u.

## Kabul kriterleri
- [ ] `_TRGM_INDEXES`'e üç giriş: `idx_case_foys_tku_no_trgm` (`case_foys`, `tku_no`), `idx_case_foys_sistem_no_trgm` (`case_foys`, `sistem_no`), `idx_case_foys_onceki_tracking_no_trgm` (`case_foys`, `onceki_tracking_no`).
- [ ] `idx_cases_tku_no_trgm` ve `idx_cases_sistem_no_trgm` sözlükten ÇIKARILIR ve `_DUSURULECEK_INDEXLER["cases"]`'e eklenir (sözlükte kalsa her açılışta yeniden yaratılırdı — G042 dersi). `idx_cases_tku_no` btree index'i varsa (op ya da `models.py index=True` kaynağı bulunup) aynı listeye; kaynağı kaldırılır ki tekrar yaratılmasın. `uq_cases_sistem_no` DOKUNULMAZ.
- [ ] Yeniden yaratma tuzağı testi: `test_index_envanteri`'deki iç tutarlılık testi (düşürme listesindeki ad `_TRGM_INDEXES`'te YOK) yeşil kalır; yeni üç ad için "sözlük → CREATE INDEX ... USING gin (... gin_trgm_ops)" DDL üretimi testi.
- [ ] `dbtest`: scratch DB'de `init_db()` sonrası üç yeni index VAR, iki eski index YOK; ikinci `init_db()` idempotent (aynı sonuç, hata yok).
- [ ] Lokal ölçüm (rapora): `_search_term_ids("<bir TKU no>", False)` EXPLAIN'inde `case_foys` üç kolu Bitmap Index Scan'e döner; önce/sonra buffer ve süre.
- [ ] `docs/kararlar/018-index-temizligi-37-kalem.md`'ye tarihli ek: "14.09 denetimi: legacy kolon index'leri boş kolondaydı; `case_foys`'a taşındı; `cases` altı trgm index'i hâlâ geri eklenmedi, karar G190 EXPLAIN kanıtına bağlı".
