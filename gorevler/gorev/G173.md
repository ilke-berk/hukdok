## Hedef

Kullanıcı kararı (11.09 gündüz): rapor ekranı "deli gibi" sadeleşir — manuel kurucu (kaynak kartları, filtre şeridi, kolon
yan paneli) KALKAR, sohbet tek giriş noktası olur. Ama üç şey sohbetin ALTINDA korunur: (1) şeffaflık — uygulanan tanım her
an görünür, (2) elle düzeltme kanalı — asistan yanlış eşlerse kullanıcı tıklayıp düzeltir, (3) değer listeleri — mahkeme adı
gibi 300 önerili kutular çip düzenlemesinde açılır. Bu görev o katmanı kurar: `TanimSeridi`, `OlusturucuDurumu`'nu tek satırlık
(saran) bir çip şeridi olarak çizer ve yerinde düzenletir. Sayfaya bağlama G175'te; burada bileşen + test.

G169-G172 (üç aşama planı) bu kararla İPTAL edildi (KUYRUK'ta BLOKE(İPTAL)); onların teşhisi (bağlı kaynak kolonları 145
kolonluk listede kayboluyor) burada "+ Kolon" combobox'ının grup başlıklarıyla karşılanır.

## Tasarım (bağlayıcı)

Şerit tek `<div role="group" aria-label="Rapor tanımı" data-testid="tanim-seridi">`, `flex flex-wrap gap-2`, tam genişlik
(max-w cap YOK — feedback kuralı). Sırayla:

1. **Kaynak rozeti** `data-testid="serit-kaynak"`: `"Davalar ▾"` — `DropdownMenu` (`ui/dropdown-menu.tsx`) ile
   `katalog.veri_kaynaklari` listesi (etiket + açıklama). Seçim → `onKaynakSec(anahtar)` (sayfa `kaynakIcinBaslangic` ile
   sıfırlar; onay diyaloğu sayfanın işi, şerit yalnız çağırır). Aynı kaynağa tık no-op.
2. **Kolon çipleri** `data-testid="serit-kolon-<anahtar>"`: etiket; bağlı kaynak kolonunda (`kolon.bag != null`) önek
   `"<İlişki etiketi> · "` ve ayrık renk çubuğu (`ui.ts` eşlemesi: ana kaynak + her ilişki için ayrı renk, tema token'larıyla).
   `×` kaldırır (`kolonKaldir`); son kolon kaldırılamaz (düğme disabled + title). Sürükle-sırala bu görevde YOK (ColumnPicker'daki
   dnd-kit listesi kalkıyor; sıra = ekleme sırası; ↑↓ da yok — kullanıcı isterse sonra).
3. **"+ Kolon"** düğmesi → `Popover` + `Command` (cmdk, `ui/command.tsx`; `FilterControl.MetinCombobox` deseni): arama kutusu,
   `CommandGroup` başlıkları = `kolon.grup` (ana kaynak) ve `"<İlişki etiketi> · <grup>"` (bağlı); yalnız `secilebilir` ve henüz
   seçilmemiş kolonlar; `kolon_setleri` en üstte "Hazır setler" grubu (seçince set kolonları eklenir, tekrar yok). 60 tavanı
   (`TANIM_LIMITLERI.kolon_max`): dolunca düğme disabled + "En çok 60 kolon".
4. **Filtre çipleri**: mevcut `FilterChip` (`SeritOgesi` + `KatalogKolon`) AYNEN; ek olarak çipin gövdesine tık →
   `Popover` içinde mevcut `FilterControl` (aynı `SeritOgesi`, `onDegistir`; yazarak girilen değer `gecikmeli=true`, odak
   çıkışı `onHemen`). `×` kaldırır. Boş kontrol (`kontrolDoluMu` false) çip olarak GÖRÜNMEZ ama durumda kalır (QuickFilters
   davranışı) — kullanıcı "+ Filtre" ile eklediği alanın popover'ı açık gelir, doldurmadan kapatırsa çip yok.
5. **"+ Filtre"** → mevcut `FieldPicker` (alan arama, bağlı kaynak kolonları dahil, `filtrelenebilir` olanlar) → `filtreEkle`
   (`eklenenOge(bosKontrol(kolon))`, `hizli:false`) + popover açık. 20 tavanı (`filtre_max`): dolunca disabled.
6. **Sıralama çipleri** `data-testid="serit-siralama-<alan>"`: `"↑ Açılış tarihi"` / `"↓ …"`; `×` kaldırır. Ekleme yolu tablo
   başlığı (PreviewTable, değişmez); şeritte "+ Sıralama" YOK.
7. **Temizle** (sağda, `serit-temizle`): filtreleri boşaltır, kolonlar kaynağın varsayılanına döner (`kaynakIcinBaslangic`
   ile aynı sonuç, sayfa onayı gerekmez — geri al sayfanın işi değil; bu görevde `onChange` ile yeni durum verilir).

Prop sözleşmesi (G175 bunu bağlar — DEĞİŞTİRME):
```ts
interface TanimSeridiProps {
  katalog: Katalog;
  durum: OlusturucuDurumu;
  onChange: (durum: OlusturucuDurumu, gecikmeli?: boolean) => void;  // sayfa durumDegisti
  onHemen: () => void;                                                // odak çıkışı → önizleme hemen
  onKaynakSec: (anahtar: string) => void;
  bugun?: string;                                                     // tarih kısayolları için (QuickFilters ile aynı)
  salt?: boolean;                                                     // true → düzenleme kontrolleri gizli (ileride)
}
```
