### 1. Ölçüm yöntemi — `pip-audit` neden koşulamadı

Bu görev `docs` bandında, `C:\dev\hukudok-wt\G022` worktree'sinde koştu. Bantta
`docker` yasak (`otomasyon/kuyruk-kosusu.ps1:158` `$yasakWorktree`), host'ta `pip-audit`
kurulu değil ve `pip install` izin kapısında yok. Denendi ve reddedildi:
`docker ps`, `docker exec hukdok_backend pip --version`.

Bunun yerine **`pip-audit`'in varsayılan zafiyet servisi** (`--vulnerability-service pypi`)
olan PyPI JSON API'si, `requirements.txt` + `requirements-dev.txt` içindeki **28 sabit
sürümün her biri** için tek tek sorgulandı; mükerrer kimlikler (GHSA/CVE/PYSEC/BIT alias
grafiği) birleştirilerek distinct sayısı çıkarıldı. Veri kaynağı `pip-audit` ile aynı;
**farkı kapsam:** yalnız doğrudan pinler taranır, transitif kapanış taranmaz.

> **İzlenecek (ADR'de de yazılı):** uygulama işine başlamadan önce
> `docker compose exec -T backend pip-audit` backend bandında koşulmalı; sayılar farklıysa
> o çıktı geçerlidir.

Koşulan komutlar (kanıt):

```
python -c '... PyPI JSON API, 28 pin ...'      # ssl.VERIFY_X509_STRICT kapatıldı — AVG CA
npm --prefix frontend audit
npm --prefix frontend audit --omit=dev
npm --prefix frontend audit --json > g022-npm-audit.json           (geçici, silindi)
npm --prefix frontend audit --omit=dev --json > ...-prod.json      (geçici, silindi)
npm --prefix frontend view @remix-run/router version --json   → "1.23.3"
npm --prefix frontend view vite@8.2.1 engines --json          → ^20.19.0 || >=22.12.0
```

*Not:* host Python'ın TLS'i AVG araya girmesi yüzünden `CERTIFICATE_VERIFY_FAILED
(Basic Constraints of CA cert not marked critical)` verdi — Python 3.13'ün varsayılan
`VERIFY_X509_STRICT` bayrağı kapatılarak (zincir + hostname doğrulaması korunarak) aşıldı.
Bilinen tuzağın yeni bir yüzü.

   (tetikleyicisi yazıldı).

   ön koşulu; kendi başına da bir tekrarlanabilirlik arızası.

   bir saldırgan sınırsız dışa istek üretebilir (PYSEC-2026-177, fix 2.13.0). Bu, ADR'nin
   4. adımının aciliyet gerekçesi.
3. **`backend/requirements.txt` transitif bağımlılıkları sabitlemiyor** (lock yok) →
   imajdaki starlette/anyio/certifi sürümü repodan okunamıyor; her `docker build`

   (`fastapi==0.121.3` → `starlette<0.51.0`; aralıktaki her sürüm ≥10 kayıt; ilk temiz
