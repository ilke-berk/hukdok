- **Bant:** backend
- **Bağımlı:** -
- **Dosya kapsamı:** backend/required_fields.py (`responsible_lawyer_name` kuralı `:57` + SQL ikizi `:202-207`
  çevresi), backend/managers/case_manager.py (yalnız `refresh_missing_required` çağrı yolu gerekiyorsa),
  backend/tests/test_g158_coklu_avukat_eksik.py (YENİ)
- **Dokunma:** backend/scripts/hukdok_aktarim.py, backend/managers/lawyer_resolver.py, frontend/**

## Test değiştirme İZNİ (baştan)

**İZİNLİ:** `tests/test_required_fields.py` ve `tests/test_g046_missing_required.py`'de "responsible_lawyer_name boş →
eksik" beklentileri, yalnız `case_lawyers` satırı olan senaryolar eklenerek. **KİLİT:** diğerleri.

## Hedef

Plan 08.09 §1.3 **M5** (kullanıcı kararı 08.09). Ekip: 1.031 föy 12 avukata "atanmış" değil, sorumlu avukatı
ayrıştırılamamış eski dosya; "silmeyin, boşaltmayın, atanmadı saymayın". Bizde çoklu isimde `responsible_lawyer_name`
NULL, isimler `case_lawyers`'ta (`hukdok_aktarim.py:605-613`, `:1768-1801`); kutu boş olduğu için kart
`missing_required_bucket=AKTARIM` kovasına düşüyor (`required_fields.py:57`) → 1.031 kart "eksik" gürültüsü.

## Yapılacaklar

1. Kural: `responsible_lawyer_name` boş **ve** kartın `case_lawyers` satırı ≥ 2 ise alan eksik SAYILMAZ (sorumlu
   belirsiz, atanmamış değil). Tek satır varsa kutu da dolu olmalı (aktarım zaten yazar) — eksik kalır.
   Hem Python kuralı hem SQL ikizi (`required_fields.py:202-207`, `EXISTS (select 1 from case_lawyers …)`).
2. Backfill: `refresh_missing_required` toplu yenileme yolu varsa çağrı; yoksa küçük `--apply`'lı script
   (dry-run varsayılan). Lokalde ölçüm: AKTARIM kovası düşüşü (beklenen ≈ 1.031).
3. Testler: 0 / 1 / 2 avukat satırı senaryoları (Python + SQL aynı sonuç); backfill idempotent.

## Kabul kriterleri

- [ ] Çoklu avukatlı, kutusu boş kart eksik sayılmaz; tek avukatlı boş kutu eksik (test, Python + SQL).
- [ ] Lokal backfill sayısı raporda; ikinci koşu 0.
- [ ] ruff + mypy temiz; pytest özet satırı; değiştirilen test → gerekçe.

## Doğrulama

- `docker compose exec -T backend python -m ruff check .`
