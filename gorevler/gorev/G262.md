- **Bağımlı:** - (uç adları plan §3 ile sabit: `emsal-belge`, `emsal-ara`, `emsal-sonuc`, `emsal-durum`)
- **Dosya kapsamı:** `nginx.conf` (yalnız Lexis location'ı `:216-235` ve üstündeki yorum), `frontend/vite.config.ts`
  (yalnız `/lexis-api/` proxy satırı `:80`), `backend/tests/test_nginx_lexis.py` (`ALLOWLIST` sabiti + yeni
  `proxy_buffering off` ve `client_max_body_size` testleri), `CLAUDE.md` ("Lexis rapor aracı önizlemesi" paragrafındaki
  allowlist listesi)
- **Dokunma:** Hukukbot bloğu (`nginx.conf:172-207`), diğer location'lar, güvenlik başlıkları, `backend/**` (test dışı),
  `frontend/src/**`, `docs/mimari/**` (G266)

## Hedef
Lexis servisinin yeni uçları tarayıcıya yalnız konteyner nginx'i ve Vite dev proxy'si üzerinden açılır; NDJSON akışı
tamponlanmadan geçer; belge yüklemesi 20 MB'a kadar kabul edilir. Allowlist bilinçli karar olarak bekçi testiyle kilitlenir.

## Kabul kriterleri
- [ ] `nginx.conf` Lexis location regex'ine `emsal-belge|emsal-ara|emsal-sonuc|emsal-durum` eklenir; `(/|$)` çapası, `~`
      (büyük/küçük duyarlı) ve `rewrite … break` aynen; `/health` yine 404.
- [ ] Aynı location'a `proxy_buffering off;` (Hukukbot bloğundaki gerekçe yorumuyla: NDJSON akışı) ve
      `client_max_body_size 20M;` (2M yerine; gerekçe: belge yüklemesi — Word JSON gövdesi küçük kalır). `add_header` YOK.
- [ ] `test_nginx_lexis.py`: `ALLOWLIST` sabiti güncellenir; yeni testler `proxy_buffering off` ve `client_max_body_size 20M`
      satırlarını Lexis gövdesinde arar; Vite proxy allowlist'i nginx'tekiyle AYNI (mevcut test varsa onu genişlet).
- [ ] `vite.config.ts` `/lexis-api/` proxy regex'i aynı dört uçla; `bypass: () => false` kapanış satırı değişmez.
- [ ] `CLAUDE.md` Lexis paragrafındaki allowlist listesi dört uçla güncellenir (başka cümle değişmez).
- [ ] Konteyner nginx'i yeni konfigle açılır: `docker compose build frontend && docker compose up -d frontend` →
      `docker compose exec -T frontend nginx -t` temiz; `curl -s -o /dev/null -w "%{http_code}" -X POST
      http://127.0.0.1:8080/lexis-api/emsal-ara` servise ulaşır (Lexis servisi açıksa 401/404/422 SERVİSTEN; kapalıysa
      502 — ikisi de nginx 404'ü DEĞİLDİR; Rapor'a hangisi görüldü yazılır) ve
      `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8080/lexis-api/health` 404.
