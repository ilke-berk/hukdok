# G199 — requests 2.34.2 + `activity_manager.py` Graph payload tipi

- **Bant:** backend
- **Bağımlı:** G198 (`requirements.txt` ortak; backend seri)
- **Dosya kapsamı:** `backend/requirements.txt` (yalnız `requests` satırı), `backend/managers/activity_manager.py` (yalnız `:244-256` civarı payload tip açıklaması), mypy'nin yeni sürümle işaretlediği başka `requests.*(json=...)` çağrıları varsa onların yalnız tip açıklaması
- **Dokunma:** istek davranışı (URL, header, timeout, payload içeriği), diğer bağımlılık satırları

Kaynak: `docs/arsiv/bagimlilik-raporu-2026-09.md` §4 + §5.2.

## Hedef
24.09 denetiminde `requests 2.33.0 → 2.34.2` bölmede elendi: 2.34 typeshed yerine satır içi tip getirdi ve mypy
`managers/activity_manager.py:256: Argument "json" to "post" has incompatible type "dict[str, Collection[str]]";
expected "JsonType | None"` verdi. `payload` sözlüğüne açık tip (`dict[str, Any]`) verilir, sürüm çekilir. Davranış
değişmez — yalnız tip.

## Kabul kriterleri

- [ ] mypy temiz; `git diff backend/managers` yalnız tip açıklaması/import (`Any`) içerir, çağrı argümanları aynı.
- [ ] Tam pytest + ruff yeşil; sayılar rapora.
- [ ] Rapor: requests 2.33→2.34 sürüm notu özeti + projedeki `requests` kullanım yerleri (grep) ve etkilenip etkilenmedikleri.

  Çağrı argümanları (URL, header, `json=payload`, `timeout=30`) ve payload içeriği AYNI — yalnız tip açıklaması.

**Kararlar**

görülmedi (tam pytest yeşil). Sürüm notlarının ayrıntısı bu oturumda dışarıdan okunmadı.
