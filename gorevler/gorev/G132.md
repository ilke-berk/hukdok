# G132 — Rapor asistanı: Gemini JSON şemalı sohbet ucu (NDJSON), admin anahtarı, model env'i

- **Bant:** backend
- **Bağımlı:** G131
- **Dosya kapsamı:** backend/services/rapor/asistan.py, backend/prompts.py (`get_rapor_asistani_instruction`),
  backend/schemas_rapor.py (`RaporAsistanCevabi`, `SohbetIstegi`), backend/routes/reports.py (`/chat`),
  backend/services/app_settings.py (`rapor_asistani` anahtarı), backend/config/settings.py
  (`GEMINI_RAPOR_MODEL`), .env.example, backend/tests/test_g132_rapor_asistani.py
- **Dokunma:** backend/analyzer.py (`_gemini_call_with_retry`, `_failed_event`, `_ensure_response_text` yalnız
  İMPORT edilir, değiştirilmez), backend/gemini_client.py, backend/case_intake_analyzer.py (desen kaynağı)

## Hedef

Kullanıcı rapor ekranındaki sohbet panelinde doğal dille ister ("2025'te açılan, karar tarihi boş
derdest davaları avukat adıyla listele, Excel ver"); asistan katalog anahtarlarıyla geçerli bir
`RaporTanimi` + kısa Türkçe açıklama + isteğe bağlı `eylem` döner. Asistan DB'ye dokunmaz, satır görmez
(K6); indirme frontend'in `/export` çağrısıyla olur (K7). Sözleşme plan §2.6, anahtar K8, env K9.

## Yapılacaklar

1. **Prompt (`prompts.py`):** sistem talimatı kataloğu kompakt gömer (kaynak → `anahtar·etiket·tip[·seçenekler]`
   satırları; registry'den üretilir, elle liste YOK). Kurallar: yalnız katalog anahtarları; belirsizse soru
   sor ve `tanim=null`; `mevcut_tanim` verildiyse onu değiştirerek üret; "indir"/"Excel"/"CSV" isteğinde
   `eylem`; kullanıcıya veri döndürme; Türkçe, kısa.
2. **`services/rapor/asistan.py`:** `async def sohbet(mesajlar, mevcut_tanim, tenant_id) -> AsyncIterator[dict]`
   — `contents` listesine son 20 mesajı rol eşleyerek koyar (`user`/`model`), `GenerateContentConfig(
   system_instruction, response_mime_type="application/json", response_schema=RaporAsistanCevabi)`,
   çağrı `analyzer._gemini_call_with_retry(..., model=get_rapor_model())`
   (`case_intake_analyzer.py:245-269` deseni). Dönen `tanim` **aynı `RaporTanimi` + registry doğrulamasından**
   geçer; geçmezse `warning` olayı + `tanim=null`. Olaylar plan §2.6; hata eşlemesi `_failed_event`
   etiketleriyle (`GeminiCircuitOpenError`/429 → `gemini_saturated`, güvenlik → `gemini_blocked`,
   MAX_TOKENS → `gemini_truncated`, JSON/şema → `schema_invalid`).
3. **Uç:** `POST /api/reports/chat` → `StreamingResponse(media_type="application/x-ndjson")`
   (`routes/processing.py:573` deseni); `require_admin`; anahtar kapalıysa akış açılmadan **409**.
   İstek gövdesi sınırı: mesaj ≤ 20, her `icerik` ≤ 4000 karakter (422).
4. **Anahtar:** `SETTINGS_REGISTRY["rapor_asistani"]` — label "Rapor asistanı (AI)", açıklama Gemini
   kullanımını ve kapalıyken manuel raporun çalışmaya devam ettiğini söyler; varsayılan **False** (K8).
5. **Env:** `GEMINI_RAPOR_MODEL` (yoksa `GEMINI_INTAKE_MODEL` değeri); `.env.example` şerhi.
6. **Test:** sahte Gemini (`monkeypatch analyzer._gemini_call_with_retry`) ile: geçerli tanım → `complete`
   + `tanim` dolu; katalog dışı kolon üreten cevap → `warning` + `tanim=null` + yine `complete`;
   429/devre kesici → `failed gemini_saturated`, tek ERROR log (`caplog`); anahtar kapalı → 409;
   yönetici değil → 403; mesaj limiti 422; `mevcut_tanim` prompt'a girer (payload assert).

### Kararlar + gerekçeleri

- **Gemini şeması `RaporTanimi` DEĞİL, ayrı `AsistanTanimi`:** konteynerde `google.genai._transformers.t_schema`
  ile ölçüldü — `RaporTanimi` (`extra="forbid"`) `additional_properties:false` üretir (SDK Developer API modunda
  `additionalProperties`'i desteklemez; truthy'yi reddeder, `false`'u süzmeden API'ye yollar) ve `Filtre.deger: Any`
  TİPSİZ özellik üretir. Asistan şemasında filtre değeri metin (`deger`) ya da metin listesi (`degerler`,
  `in`/`between`); sunucu kolon tipine göre çevirir (mantık `true/false/evet/hayır`, sayı/para int/float, tarih
  strip) ve sonucu **aynı** `RaporTanimi` Pydantic + `motor.tanimi_dogrula` yolundan geçirir (K6 tek doğrulama).
  Çevrilemeyen değer metin kalır ve motor reddeder → `warning` + `tanim=null`.
- **`analyzer` tembel import:** modül import'unda `GEMINI_MODEL_NAME` zorunlu (yoksa ValueError). `routes/reports.py`
  asistanı import eder; CI (`ci.yml`) ve G130/G131 testleri bu env olmadan `routes.reports`'u yükler →
  `_analyzer()` çağrı anında import eder (`routes/case_intake.py` aynı nedenle intake motorunu route içinde import
  eder). Testler `analyzer._gemini_call_with_retry`'ı monkeypatch'ler; erişim modül özniteliğinden olduğu için işler.
- **Kapı sırası 403 → 409 → 422:** anahtar kapalıyken gövde hiç ayrıştırılmaz ("akış açılmadan 409"). Test bunu kilitler.
- **Geçersiz tanımda `eylem` de düşer:** tanım doğrulanamadıysa `eylem=null` — istemci geçersiz/eski tanım üzerinde
  indirme başlatmasın. Asistan bilinçli `tanim=null` (soru) döndüğünde `eylem` prompt gereği zaten null.
- **Baştaki asistan mesajları atılır:** Gemini `contents` kullanıcıyla başlamalı; arayüz karşılama mesajıyla açabilir.
  Son mesajın `user` olması 422 ile zorlanır (`SohbetIstegi` validator).
- **Hata özeti + `Kod:` kimliği:** `analyzer._api_error_ozet` deseni; devre kesici ve 429/5xx `gemini_saturated`
  (`analyzer._api_error_kod` ile aynı kod bazlı sınıflandırma — import-only kullanım, analyzer değişmedi).
- **Sohbet geçmişi sunucuda saklanmaz** (K6); `tenant_id` yalnız ERROR log bağlamı — tanım tenant filtresini
  çalıştırıldığı uçta alır (`/preview`, `/export`; K2).
- `.env.example` görev kapsamında (G131 ile aynı); sır içermeyen şablon dosyası, yalnız şerh satırı eklendi.
