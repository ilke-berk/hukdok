## Hedef
Avukat Word'den çıkmadan HUKDOK şeridindeki düğmeyle sağ bölmeyi açar, kartı seçer, açık belgeyi taslak olarak kaydeder,
sürüm notu yazar, kesinleştirir. Dağıtım Microsoft 365 yönetici merkezinden (İNSAN ADIMI; rapor adımları yazar).

## Kabul kriterleri
- [ ] `/eklenti` rotası `ProtectedRoute` dışında; sayfa `Office.onReady` bekler (Office dışında açılırsa "Bu sayfa Word
      içinde çalışır" + HUKDOK'a bağlantı), ardından `kimlik.ts` ile sessiz giriş; NAA kullanılamıyorsa `loginPopup` yedeği
      (G286 ölçümüne göre; hangisinin seçildiği rapora).
- [ ] `KartSec`: dava arama (G273 arama bileşeni yeniden kullanılır, dar düzen), seçilen kart künyesi, "değiştir".
- [ ] `TaslakKaydet`: açık belge `getFileAsync` → docx `Blob` (dilim birleştirme + `closeAsync`); belge daha önce karta
      bağlı değilse "Taslak olarak kaydet" (tür + ad → `yeni` + dosya) → bölmede belge kimliği saklanır
      (`Office.context.document.settings` ile belgeye gömülü `hukdok_document_id`); bağlıysa "Sürüm kaydet" (not) ve
      "Kesinleştir" (`KesinlestirOnayi` yeniden kullanılır).
- [ ] `EklentiDurum`: kayıtlı kart + belge adı + sürüm sayısı + durum; "HUKDOK'ta aç" bağlantısı (yeni sekme).
- [ ] Manifest geçerli (Office manifest şemasına göre `npx office-addin-manifest validate` çalıştırılabiliyorsa çıktısı
      rapora; paket kurulmaz, `npx` ile tek seferlik); ikonlar `public/eklenti/ikon-{16,32,80}.png` (HUKDOK rozetinden).
- [ ] Yönetici dağıtım adımları `docs/mimari/kimlik-ve-token.md` ya da `docs/mimari/deploy-ve-altyapi.md`'ye bir bölüm
      (Microsoft 365 yönetici merkezi → Tümleşik uygulamalar → Özel uygulama yükle → manifest URL'si; test kullanıcısına
      önce; sonra herkese) — İNSAN ADIMI işaretli.
- [ ] Testler: `Office` nesnesi sahte (`globalThis.Office`); `getFileAsync` dilim birleştirme; kart seçimi → `yeni` gövdesi;
      belge kimliği `settings`'ten okunur; Office dışı açılış mesajı.
- [ ] CSP'ye uyum: sayfa inline script KULLANMAZ; Office.js `script` etiketi G286'un izin verdiği kaynaktan dinamik eklenir.
