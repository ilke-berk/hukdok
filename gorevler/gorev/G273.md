## Hedef
Tezgâhtaki dosya tek diyalogla kartın belgesi olur; kartın belgeleri tek tıkla tezgâha gelir; gerçek backend'le zincir
(yükle → işlem → karta bağla → kartta görünür) kanıtlanır.

## Kabul kriterleri
- [ ] `KartaBaglaDiyalogu` (`theme-classic` taşır — portal kabuğun dışında): dava arama kutusu (mevcut dava arama API'si,
      tuş vuruşu yolu, ofis no / esas no / taraf adıyla), seçilen kartın künyesi; belge türü seçici (mevcut doctype
      listesi, `_` padding'li kod gönderilir, etiket gösterilir); taraf seçici (opsiyonel, kartın `parties`'i); dosya adı
      (varsayılan `Dosya.ad`); `istek_kimligi` `crypto.randomUUID()` diyalog açılışında üretilir, tekrar tıklama aynı
      kimlikle gider (`reused: true` → "zaten bağlı" bilgisi); başarıda toast + karta bağlantı (`/cases/{id}`); 409 kilitli
      kart mesajı; 503 meşgul.
- [ ] `KarttanAlDiyalogu`: dava ara → kartın belge listesi (`GET /api/cases/{id}` `documents`, `sharepoint_url` dolu
      olanlar seçilebilir, diğerleri soluk "arşivde yok") → çoklu seçim → her biri `karttanAl(document_id)` (sırayla) →
      tezgâh listesine düşer; "hepsini birleştir" kısayolu seçilen sırayla `birlestir` çağırır.
- [ ] `CaseDetails` belge satırı menüsü: "PDF araçlarında aç" → `navigate("/pdf-araclari", { state: { document_ids: [id],
      case: {...} } })`; belgeler sekmesinde çoklu seçim şeridi (tik + "Seçilenleri PDF araçlarında birleştir") aynı
      `state` ile `document_ids` listesi. Sayfa açılışında `state.document_ids` varsa `karttanAl` sırayla koşar, `state.case`
      Karta bağla diyaloğunda ön-seçilidir.
- [ ] Sözleşme hizası: gerçek backend'le (G269 main'de) `docker compose up -d` stack'inde kullanıcı token'ı gerektirir —
      gece koşusunda giriş YOK; bu yüzden hizalama **test ile**: `backend/tests/test_pdf_araclari_*`'ın Pydantic
      modellerindeki alan adları `types/pdfAraclari.ts` ile karşılaştırılır (işçi raporda tabloyla gösterir); fark
      bulunursa plan §3 düzeltilir ve iki taraf da bu görevde hizalanır (backend dosyasına dokunmak gerekirse BLOKE
      bırak, gerekçeyle).
- [ ] Testler: diyalog gövdesi doğru (`belge_turu_kodu` padding'li, `istek_kimligi` sabit kalır), `reused` mesajı, 409,
      karttan al sıralı çağrı, `CaseDetails` menü → `navigate` state'i, sayfa açılışı state'ten ön-yükleme.
