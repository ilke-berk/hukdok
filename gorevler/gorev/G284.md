## Hedef
Avukat kartta "Yeni belge" deyince SharePoint'te Word taslağı açılır; istediği kadar sürüm kaydeder; "Kesinleştir" aynı
belgeyi PDF/A yapıp arşive ve kartta "giden/kesin"e çevirir; düzeltme yeni taslak olur, gönderilen değişmez.

## Kabul kriterleri
- [ ] `POST /api/cases/{id}/belgeler/yeni` `{"belge_turu_kodu", "ad", "sablon"?: "bos", "case_party_id"?}`: kart tenant +
      soft-delete süzgeci (404); tür normalize (422); `ad` `sanitize_filename` + `.docx` zorlanır; hedef
      `f"{settings.sharepoint_folder_taslak_name}/{ofis_no}"` (ofis no `cases.tracking_no`; boşsa `kart-{id}`); ad çakışması:
      `get_file_meta_from_sharepoint` ile bakılır, varsa `-2`, `-3` … (en çok 20; sonra 409); `bos.docx` kopyası
      `upload_file_to_sharepoint(..., use_date_subfolder=False)` (senkron — kullanıcı Word'ü hemen açacak); kayıt
      `save_case_document(..., yon="GIDEN", kaynak="WORD", durum="TASLAK", sharepoint_url=webUrl, word_url=webUrl, link_mode="LINKED")`;
      yanıt `{"document_id", "word_url", "word_ac": f"ms-word:ofe|u|{word_url}"}`. SharePoint hatası 502.
- [ ] `POST /api/documents/{id}/surum` `{"not"?}`: belge TASLAK + `word_url` dolu değilse 409; SharePoint'ten indirilir
      (`download_file_from_sharepoint`), sha256 + eTag; `belge_surumleri` yeni satır `surum_no = max+1`, `kesin=false`;
      yanıt `{"surum_no", "sha256", "degisti": sha != önceki}`; belge boyutu `max_upload_mb` aşarsa 413.
- [ ] `GET /api/documents/{id}/surumler`: tenant süzgeci; `surum_no` artan liste; KESIN belgede son satır `kesin=true`.
- [ ] `POST /api/documents/{id}/kesinlestir` `{"istek_kimligi"}`: TASLAK değilse 409; `.docx` indirilir →
      `convert_to_pdfa2b(time_budget=pdf_araclari_butce_saniye)` (`ConversionBusyError` 503) → AYNI satır: `durum="KESIN"`,
      `kesinlesme_tarihi=now`, `kesinlestiren_email`, `stored_filename=<ad>.pdf`, `sharepoint_url` **NULL'a çekilir** (URL
      commit'i upload_queue'da — bildirim/Hukukbot o anda tetiklenir, G282 filtresi artık geçirir) → `enqueue_upload("islenmis",
      pdfa, <ad>.pdf, ISLENMIS_FOLDER, document_id)` + `enqueue_upload("ham", docx, <ad>.docx, HAM_FOLDER)`; son sürüm satırı
      `kesin=true` (sha = docx); idempotent `istek_kimligi` (`confirm_idempotency` deseni, anahtar `kesinlestir:<uuid>`) →
      `reused:true`. Taslak `.docx` `03_TASLAKLAR`'da KALIR (silinmez; "Word'de aç" artık salt okunur gösterim — frontend).
- [ ] `POST /api/documents/{id}/yeni-surum-taslagi` `{"istek_kimligi"}`: KESIN değilse 409; ham arşivdeki `.docx` indirilip
      taslak klasörüne `<ad>-v{n}.docx` olarak yüklenir; yeni satır TASLAK/GIDEN/WORD, `onceki_document_id=id`; idempotent.
- [ ] Tür allowlist ve Hukukbot: kesinleşen belge tür allowlist'teyse `export_outbox`'a düşer (upload başarısında) — test
      mevcut `export_publisher` testleri gibi; TASLAK iken düşmediği G282'te kanıtlı.
- [ ] Log: nihai hata TEK ERROR (`error_kod`: `sharepoint`, `donusum_basarisiz`), 4xx WARNING.
- [ ] Testler: SharePoint fonksiyonları sahte (monkeypatch — ad çakışması senaryosu `-2`), `convert_to_pdfa2b` sahte,
      `enqueue_upload` sahte; in-memory SQLite + `dependency_overrides`; kesinleştir iki kez → tek işlem; yeni-sürüm zinciri
      `onceki_document_id`; `bos.docx` geçerli zip + `word/document.xml` içerir (test açar).
