# G018 — Altyapı: gzip, eksik preview proxy'si, init:true, backend/.dockerignore

- **Bant:** backend *(altyapı dosyaları backend bandı sayılır — doğrulaması ayakta stack ister)*
- **Bağımlı:** -
- **Dosya kapsamı:** nginx.conf, docker-compose.yml, backend/.dockerignore (YENİ), frontend/vite.config.ts (yalnız dev proxy allowlist'i)
- **Dokunma:** docker-compose.override.yml.example, infra/**, frontend/src/** (vite.config.ts DIŞINDA hiçbir frontend kaynağına dokunma — vitest bu değişiklikten etkilenmez)

## Hedef

Plan FAZ A.1 + A.3 + 0.7 + A.2'nin otomatiklenebilir kısmı. Dört küçük, davranışsız
(ya da açıkça arıza düzelten) altyapı düzeltmesi:

**1. gzip kapalı (A.1).** `nginx.conf`'ta `gzip` geçen tek satır yok. Ölçüldü: JS chunk'ı
**1.324.033 bayt** ham, gzip'li karşılığı **361.003 bayt**. `curl -H 'Accept-Encoding: gzip'`
yanıtında `Content-Encoding` başlığı yok. Repo genelinde (`*.md`, `*.conf`, `*.yml`) gzip'ten
söz eden tek satır bulunamadı — yani başka katmanda bilinçli yapıldığına dair kanıt da yok.

**2. `/preview-client-email-body` proxy'lenmiyor (0.7).** `nginx.conf` location listesi:
`/`, `= /healthz`, `/api`, `/process`, `/confirm`, `/preview-email-body`, `/refresh`.
Müvekkil olanı **yok** → müvekkil bilgilendirme AI metni sessizce yanlış tonlu frontend
fallback'ine düşüyor. `frontend/vite.config.ts` dev proxy'sinde **ikisi de yok**, yani
`npm run dev` ile çalışan geliştirici avukat önizlemesinin de düştüğünü görür.
Aynı allowlist üç yerde elle tutuluyor (nginx.conf, vite.config.ts, `frontend/src/lib/api.ts`
`LONG_TIMEOUT_PREFIXES`) ve üçü de birbirinden sapmış — bu görevde **senkronize edilir**,
yeniden tasarlanmaz (route'ları `/api` altına toplama önerisi kapsam dışı).

**3. `init: true` yok (A.3).** Her soffice dönüşümü 5 zombie süreç bırakıyor (ölçüldü:
212 → 230 = 42 dönüşüm × 5); konteynerde reaper yok. `docker-compose.yml`'de backend
servisine `init: true` eklenmeli.

**4. `backend/.dockerignore` yok (A.2 kısmi).** Kökte `.dockerignore` var (92 bayt) ama
backend build context'i `./backend` (`docker-compose.yml:38`) olduğu için **uygulanmıyor**.
İmajdaki `/app` 329 MB: 134 MB legacy SQLite + 139 MB calibration + 29 MB `.mypy_cache` +
2,7 MB `tests`. Bu görev **yalnız `.dockerignore` dosyasını yazar**.

> **KAPSAM DIŞI — kullanıcı işi.** `backend/data/hukudok.db` (140 MB gerçek müvekkil verisi)
> ve `backend/calibration/` (139 MB gerçek müvekkil PDF'i) **bu görevde SİLİNMEZ/TAŞINMAZ**.
> Gerçek müvekkil verisidir, OneDrive senkronu altındadır ve silme/taşıma kararı kullanıcıya
> aittir (plan A.2). Otomasyon oturumu kullanıcı verisi silmez.

> **KAPSAM DIŞI — deploy.** Bu görev `docker compose up -d` KOŞMAZ. Değişiklikler config
> doğrulamasıyla sınanır; canlıya alınması deploy kararıdır (kullanıcıda).

## Kabul kriterleri

- [ ] `nginx.conf`'ta gzip açık; en azından JS/CSS/JSON/SVG MIME'ları kapsıyor ve makul bir
      `gzip_min_length` var. Zaten sıkıştırılmış tipler (jpg/png/pdf/woff2) kapsam dışı
- [ ] `nginx.conf`'ta `/preview-client-email-body` location'ı VAR ve `/preview-email-body` ile
      aynı proxy/timeout ayarlarını taşıyor
- [ ] `frontend/vite.config.ts` dev proxy'sinde **her iki** preview ucu da VAR
- [ ] `frontend/src/lib/api.ts` `LONG_TIMEOUT_PREFIXES` üç allowlist'le tutarlı (sapma varsa
      giderildi, raporda hangi sapma bulunduğu yazılı)
- [ ] `nginx.conf` sözdizimi doğrulandı — atılabilir konteynerde `nginx -t` (ayakta duran
      stack'e DOKUNMADAN, örn. `docker run --rm -v .../nginx.conf:...:ro nginx:alpine nginx -t`)
- [ ] `docker-compose.yml` backend servisinde `init: true`; `docker compose config` hatasız
- [ ] `backend/.dockerignore` var ve en az şunları dışlıyor: `data/`, `calibration/`,
      `.mypy_cache/`, `.pytest_cache/`, `.ruff_cache/`, `__pycache__/`, `tests/`
- [ ] `.dockerignore` **Dockerfile'ın gerçekten ihtiyaç duyduğu** hiçbir şeyi dışlamıyor —
      `backend/Dockerfile` okunup doğrulandı (özellikle fonts ve `data/` dizininin imajda
      yaratılıp yaratılmadığı); doğrulama raporda
- [ ] `mem_limit`/`memswap_limit` değerlerine DOKUNULMADI (2026-07-29 OOM dersleri)
