## Sözleşme (SABİT — değiştirirsen BLOKE bırak)
- `POST /api/transcribe`, `multipart/form-data`, tek alan `ses` (dosya). Oturum zorunlu (401).
- Kabul edilen türler: `audio/webm`, `audio/ogg`, `audio/mp4`, `audio/mpeg`, `audio/wav` (parametreler — `;codecs=opus` — atılarak karşılaştırılır). Aksi `415`.
- Boyut > 2 MB → `413`; boş dosya → `422`.
- Başarı `200 {"metin": str}` (strip'li; konuşma yoksa boş string).
- Gemini meşgul/başarısız/devre açık → `503 {"detail": "Ses şu an yazıya çevrilemedi, lütfen tekrar deneyin."}`.

  `MultiPartParser` alt sınıfıyla gövdeyi kendisi ayrıştırır; akış `2 MB + 64 KB zarf payı`nda kesilir (413).
  Gemini'ye `Part.from_bytes` ile inline gider (Files API yok). Bekçi: `test_ses_diske_tasmaz`
  (`SpooledTemporaryFile.rollover` patlatılır, 2 MB kayıt yine 200).
- **Model:** `GEMINI_MODEL_NAME` (ana analiz modeli; email_sender/date_extractor ile aynı `os.getenv` deseni
  ve aynı fallback). Yeni env YOK → `.env.example` değişmedi.
- **Retry:** analiz hattının 170 sn bütçesi kullanıcı beklerken anlamsız → 2 retry, 20 sn "yeni deneme

  kesiciyi besler, kesici açıksa çağrı yapılmaz. Denemeler WARNING (içeriksiz), nihai başarısızlık route'ta
  TEK ERROR + `health.record_gemini_error()`. ERROR satırı istisna METNİNİ taşımaz (yalnız tip + API kodu).

- **Prompt:** kabul kriterindeki cümle birebir + "Kayıtta konuşma yoksa boş yanıt döndür." eki (boş string sözleşmesi için).
