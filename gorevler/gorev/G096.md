# G096 — Token doğrulama faz 2: scp zorunlu + audience yalnız api://

- **Bant:** backend
- **Bağımlı:** -

  docs/mimari/kimlik-ve-token.md (§2 doğrulama zinciri + §6 açık kalemler satırı)

## Hedef

G092'nin gözlem modunun ikinci yarısı. G092 `scp`/`aud` biçimini **ölçmek** için
süreç başına bir WARNING bırakmıştı ("ölçmeden sıkılaştırma herkesi kilitler").
Ölçüm 2026-08-22'de lokalde **gerçek Azure AD girişiyle** yapıldı: 10 doğrulama,
**gözlem WARNING'i hiç basılmadı** → gerçek token `aud = api://<client_id>` ve
`scp` içinde `access_as_user` taşıyor. Hedef biçim doğrulandı; artık zorlanabilir.

Kapatılan bulgu: O4 — çıplak `<client_id>` audience'ı kabul edildiği için aynı
uygulamanın **ID token'ı** access token yerine geçebiliyordu.

## Yapılacak

1. `allowed_audiences` → yalnız `[f"api://{client_id}"]`. Çıplak `client_id`
   artık `InvalidAudienceError` → None (mevcut ret biçimi).
2. `jwt.decode` sonrası `scp` kontrolü: claim yoksa ya da boşlukla ayrılmış
   değerler içinde `access_as_user` yoksa → WARNING + None. Log satırı gözlenen
   `scp`'yi taşır, token'ı taşımaz.
3. `_observe_scope_audience` ve `_scope_audience_warned` **kaldırılır** — gözlem
   modunun işi bitti; artık sapma = ret. Buna bağlı G092 testleri (scp eksik/çıplak
   aud KABUL + WARNING olanlar) **ret** bekleyecek şekilde yeniden yazılır,
   silinmez; yorum değişim gerekçesini söyler.
4. `kimlik-ve-token.md`: §2 zincirine "aud yalnız api://, scp access_as_user şart"
   işlenir; §6 açık kalemlerden "scp zorunluluğu + audience daraltma" satırı düşer.

## Kabul kriterleri

      "kabul + WARNING" testi ters çevrilmiş)

- [ ] `scp` claim'i yok → ret + WARNING (test)

**Yapılanlar**

- `backend/auth_verifier.py`: `allowed_audiences = [f"api://{client_id}"]` (çıplak
  client_id düştü → `InvalidAudienceError` → mevcut ERROR + None yolu). Gözlem modu
  (`_scope_audience_warned`, `_observe_scope_audience`) tamamen kaldırıldı; yerine
  `REQUIRED_SCOPE = "access_as_user"` sabiti + `_has_required_scope(claims)`:
  `jwt.decode` sonrası `scp` boşlukla bölünür, `access_as_user` tam eleman olarak
  yoksa (claim eksik dahil) WARNING + None. WARNING gözlenen `scp` değerini taşır,

  kaldırıldığını doğrulayan test satırları.
- `backend/tests/test_auth_verifier.py`: `_token()` varsayılanı `aud=api://…`,
  `scp=access_as_user` (+ `_SCP_YOK` sentineli). G092 gözlem bölümü silinmedi,
  "kabul + WARNING" beklentileri "ret" olarak ters çevrildi ve yorumla gerekçelendi.
  Yeni kapsam: scp yok → ret+WARNING; `User.Read` → ret; alt-dizgi (`access_as_user_x`)

  kabul; her ret kendi WARNING'ini basar (bir-kez bayrağı yok); gözlem üyeleri sınıfta
  yok; 4 yolda (kabul + 3 ret) ham token/imza log'a sızmıyor.
