## Hedef
Her belge kaydı yönünü (gelen/giden), kaynağını ve taslak/kesin durumunu taşır; taslak Hukukbot'a ve bildirime GİRMEZ;
sürüm defteri tablosu hazır. PDF tezgâhı (G269) ve Word yaşam döngüsü (G284) bu alanlara yazar.

## Kabul kriterleri
- [ ] `case_documents` yeni kolonlar: `yon VARCHAR(8) NOT NULL DEFAULT 'GELEN'`, `kaynak VARCHAR(16) NOT NULL DEFAULT
      'BELGE_HATTI'`, `durum VARCHAR(8) NOT NULL DEFAULT 'KESIN'`, `word_url TEXT NULL`, `kesinlesme_tarihi TIMESTAMPTZ NULL`,
      `kesinlestiren_email VARCHAR NULL`, `onceki_document_id INTEGER NULL` (FK `case_documents.id`, `ON DELETE SET NULL`).
      Postgres'te CHECK kısıtları (`yon IN (...)`, `kaynak IN (...)`, `durum IN (...)`) AYRI `("index", ...)` op'unda
      (mevcut migrasyonlardaki idempotent `ADD CONSTRAINT` deseni); index `(case_id, durum)` ve `(durum, yon)` yine ayrı op'ta.
- [ ] `belge_surumleri`: `id`, `document_id` FK (`ON DELETE RESTRICT`), `surum_no INT`, `sha256 CHAR(64)`, `sharepoint_etag
      VARCHAR NULL`, `not TEXT NULL`, `kesin BOOLEAN NOT NULL DEFAULT false`, `olusturan_email`, `olusturulma TIMESTAMPTZ`;
      UNIQUE `(document_id, surum_no)` ayrı `("index", ...)` op'unda. Model `BelgeSurumu`.
- [ ] Backfill (koşulsuz op, idempotent): `kaynak='ARSIV_AKTARIM' WHERE uploaded_by LIKE 'ARSIV_AKTARIM:%' AND kaynak='BELGE_HATTI'`;
      başka satır değişmez (hepsi GELEN/KESIN varsayılanıyla kalır; K11).
- [ ] `constants.py`: üç tuple + `normalize_belge_yonu/kaynagi/durumu` (büyük harf, bilinmeyen → `ValueError`); yazma yolları
      bunlardan geçer.
- [ ] `save_case_document(..., yon="GELEN", kaynak="BELGE_HATTI", durum="KESIN")` ve `convert_pdfa_and_queue_uploads(...)`
      aynı üç parametreyi taşır; `/confirm` ve `case_intake` çağrıları DEĞİŞMEZ (varsayılanlar); test: mevcut confirm
      testleri geçer, yeni kayıt GELEN/BELGE_HATTI/KESIN.
- [ ] `export_publisher.enqueue_document`: `doc.durum != "KESIN"` → None (mevcut dört filtrenin yanına; docstring güncel).
      Test: TASLAK belge URL'li ve allowlist içi türde bile `export_outbox` satırı AÇMAZ; KESIN açar.
- [ ] `upload_queue._notify_document_processed`: belge TASLAK ise bildirim üretmez (test).
- [ ] Kart yanıtı (`GET /api/cases/{id}` `documents[]`): `yon`, `kaynak`, `durum`, `word_url`, `kesinlesme_tarihi`,
      `surum_sayisi` (tek `GROUP BY` alt sorgusu; N+1 YOK). `GET /api/cases/{id}/documents` `yon`/`durum` sorgu filtreleri
      (geçersiz değer 422).
- [ ] `registry.py` `belgeler` kaynağı: `yon`, `kaynak`, `durum` kolonları (kapalı liste seçenekleri sabitlerden; `eq`/`in`);
      katalog testi geçer; asistan prompt'una kolon açıklaması (bir cümle).
- [ ] `settings.py`: `sharepoint_folder_taslak_name: str = "03_TASLAKLAR"` (+ `.env.example` satırı, yorumlu).
- [ ] Migrasyon üç ortamda: `docker compose exec -T backend python migrate.py` lokalde temiz; CI çıplak Postgres'te
      `create_all` + migrasyon çakışmaz (kolon zaten varken `columns` op atlanır, CHECK/UNIQUE ayrı op'ta yine kurulur;
      test: SQLite'ta model `create_all`, Postgres'siz).
- [ ] Testler: in-memory SQLite + `dependency_overrides`; export/bildirim filtreleri; kart yanıtı alanları; liste filtresi;
