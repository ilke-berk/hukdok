# G235 — Ofis no üreticisi + DB sayacı + kategori/sigorta kod listeleri (backend temel)

- **Bant:** backend
- **Bağımlı:** G234
- **Dosya kapsamı:** `backend/services/ofis_no.py` (yeni), `backend/models.py` (yeni tablolar + kolonlar), `backend/database.py`
  (migrasyon 56), `backend/managers/seed_data.py` (kategori kodu seed), `backend/routes/admin.py` ve mevcut kategori
  yönetim ucu (kod listeleri), yeni testler `backend/tests/test_g235_ofis_no*.py`
- **Dokunma:** `managers/case_manager.py::add_case`, `routes/cases.py` (G236), `frontend/**` (G237/G241), mevcut
  `tracking_no` değerleri (göç G238'de)

## Hedef
Karar 023'teki formatı üreten TEK kanonik kaynağı sunucuda kur: saf numara kurucu + atomik sıra sayacı +
düzenlenebilir kategori kodu ve sigorta şirketi kodu listeleri. Bu görev hiçbir mevcut akışı değiştirmez; G236
(canlı tahsis) ve G238 (göç) bunu kullanır.

## Kapsam
1. `services/ofis_no.py`:
   - `kategori_kodu(kategori_adi, muvekkil_adi) -> str` — karar 023 kategori tablosu (DR/SC/HS/OH/KR/BR/DG;
     Klinik→OH, Acente/Dernek→KR; kategorisiz: şirket işareti varsa KR, yoksa BR).
   - `musteri_kodu(muvekkiller, kod_listeleri) -> (kod, secilen_muvekkil)` — karar 023 öncelik kuralları; sigortacı
     müvekkilde şirket kodu (listede yoksa `SG`).
   - `kisi_blogu(kod, ad)` — `DR.M.OZTURK`; ASCII indirme (ı/İ/ğ/ü/ş/ö/ç), noktalama ve `Dr.`/`Hem.`/`Av.` gibi unvanlar atılır.
   - `kurum_blogu(kod, ad)` — `KR.ENTHONE`; bugünkü `CORP_STOP` mantığının Python kopyası (kaynak `frontend/src/lib/caseNumberUtils.ts`).
   - `sigortali_sec(case, foys, parties)` — kaynak önceliği karar 023.
   - `tur_kodu(file_type)` — haritada olmayan → `HUK`.
   - `numara_kur(kod, sira, sigortali, tur) -> str` (saf).
   - `sira_tahsis_et(db, kod) -> int` — `INSERT ... ON CONFLICT (kod) DO UPDATE SET son_sira = son_sira + 1
     RETURNING son_sira`; iki eşzamanlı çağrı asla aynı sırayı almaz.
   - `onizle(...)` — sayacı ARTIRMADAN "bu kayıtla verilecek numara"yı döner (sıra = son_sira+1).
2. Migrasyon 56:
   - `ofis_no_sayaclari(kod PK, son_sira int NOT NULL, updated_at)`.
   - `sigorta_kisa_kodlari(id, kod UNIQUE, ad, eslesme_anahtarlari JSON — müvekkil adında aranacak kelimeler, aktif)`;
     seed karar 023 tablosu: AK, ANADOLU, AXA, CORPUS, QUICK, EUREKO, NIPPON, SOMPO, KORU, HDI, ZIRAAT (SG kodu
     sabit geri dönüştür, listede satır değildir).
   - Kategori kodu: `client_categories` tablosuna `ofis_no_kodu` kolonu (DOKTOR→DR, SAGLIK-CALISANI→SC, HASTA→HS,
     OZEL-HASTANE→OH, KURUM→KR, BIREYSEL→BR, DIGER→DG; `managers/seed_data.py::_seed_client_categories` da kodu
     taşır — dosya kapsamına eklendi). Kod listeleri arasında çakışma yasak (kategori kodu = sigorta kodu olamaz).
   - `cases`'e numaranın parçaları: `ofis_no_kodu`, `ofis_no_sira` (nullable; G238 doldurur).
   - Kalıcı index/kısıt ayrı `("index", ...)` op'unda (CLAUDE.md "koşullu/koşulsuz karışımı" tuzağı).
3. Admin uçları: `GET/POST/PATCH /api/admin/sigorta-kodlari` ve kategori kodu düzenleme (mevcut kategori ucuna
   `ofis_no_kodu` alanı ya da ayrı uç — işçi mevcut kategori yönetimini okuyup seçer). Admin yetkisi; kod değişikliği
   mevcut numaraları DEĞİŞTİRMEZ; silme yok (`aktif=false`); biçim: 2-10 büyük harf ASCII.

## Kabul kriterleri
- [ ] Karar 023 kategori ve sigorta tablolarındaki HER örnek birim testle üretiliyor (girdi: müvekkil listesi + kategori + tür + sigortalı).
- [ ] Türkçe harfli, unvanlı (`Dr.Teoman Toni Sevinç` → `DR.T.SEVINC`, `Aysel Koca Hem.` → `SC.A.KOCA`), tek kelimelik ve boş ad vakaları test edildi; boş ad `ValueError` (yer tutucu numara ÜRETİLMEZ).
- [ ] Kategorisiz: "İnka Yapı Bağlantı Elemanları San. ve Tic. A.Ş." → `KR.INKA`, "Tahsin Koç" → `BR.T.KOC`; Klinik → `OH`, Acente/Dernek → `KR` (test).
- [ ] "Anadolu Anonim Türk Sigorta Şirketi" → `ANADOLU`, "Koru Sigorta" → `KORU`, "Quick Sigorta" → `QUICK`, "Corpus Sigorta" → `CORPUS`, listede olmayan sigortacı → `SG` (test).
- [ ] Kategori kodu ile sigorta kodu çakışan kayıt reddediliyor (test).
- [ ] Sigortacı + doktor birlikte müvekkil → kod sigortacının, doktor sigortalı bloğunda (test).
- [ ] `sira_tahsis_et` eşzamanlılık testi: iki bağlantıdan paralel N çağrı → N farklı ardışık sıra (gerçek Postgres).
- [ ] `onizle` sayacı artırmaz (test).
- [ ] Migrasyon çıplak DB'de ve `create_all` sonrası DB'de idempotent (mevcut migrasyon test kalıbı).
- [ ] Admin uçları yetkisiz 403, pasif kod eşleşmede kullanılmaz (test).
